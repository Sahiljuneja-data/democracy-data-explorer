# Democracy Data Explorer

## Research Question

How has liberal democracy changed over time in India and Pakistan?

## Overview

This project explores changes in liberal democracy using the V-Dem Country-Year Dataset. I use Python and pandas to inspect, filter, analyse, and visualize the data.

The main measure used is the V-Dem Liberal Democracy Index (`v2x_libdem`).

## Data

**Source:** Varieties of Democracy (V-Dem)

**Dataset:** V-Dem Country-Year Dataset, Version 16

The analysis focuses on India and Pakistan and examines changes in the Liberal Democracy Index over time.

## Methods

The project uses:

- Python
- pandas
- matplotlib
- Descriptive statistics
- Data filtering
- Data-quality checks
- Time-series visualization

## Analysis

The project first examines the Liberal Democracy Index for India and Pakistan separately before comparing the two countries in a single time-series visualization.

## Key Observation

The Liberal Democracy Index shows substantial variation over time in both countries, with periods of democratic expansion and decline.

The visualization is descriptive and does not by itself establish causal explanations for changes in democracy.
